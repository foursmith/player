# 原生 UI 与 web 对照

以 `../../web/` v0.2.6 的实际浏览器绘制为参考。复查时同时查看组件、生成的 CSS 和 `getComputedStyle`；类名本身不足以说明最终画面。

## 已确认的参数

| 元素 | web 实际样式 | 原生实现 |
| --- | --- | --- |
| 悬浮玻璃底色 | 白色 5% 底色，仅顶部白色 14% 高光 | `appearance.go` 的 `paintGlass` |
| 悬浮按钮 | 默认无阴影，悬停叠加白色 7%，选中叠加白色 10% | `floatingIcon` |
| 设置关闭按钮 | 32px，16px 图标，白色 7% 底色、68% 图标，无玻璃描边 | `subtleIcon` |
| 音量/速度操作 | 24px，14px 图标，46% 白色，无玻璃底色 | `bareIcon` |
| 播放操作 | 桌面 48px、窄窗口 56px，图标 26px | `controls` |
| 右侧播放按钮 | 桌面 36px、窄窗口 44px，间距 8px | `controls` |
| 投影菜单 | 宽 208px、高 288px，水平对准触发按钮中心，距离按钮上边缘 10px，距窗口边缘至少 12px | `controlPopovers` |
| 音量/速度弹层 | 宽 296px，对齐控制区右侧，距离触发按钮上边缘 10px | `adjustments` |

当前 web 的 LiquidGlass 复合 `bg-[linear-gradient(...),rgba(...)]` 类未成为有效背景，计算结果为透明、无渐变。因此不应把类名中的 88% 深色底直接移植为所有按钮的填充，也不应额外添加整圈描边或图标阴影。web 的弹层阴影位于 `overflow:hidden` 容器中，外侧阴影被裁剪。

## 视频可读性适配

保留上述布局、尺寸、间距和按钮类型，同时采用以下视觉约束：

- 不绘制控件阴影或发光，不在视频上下方和设置面板后方覆盖暗色遮罩。
- 播放列表、投影菜单、音量/速度弹层等文字面板共用 96% 不透明度的中性深灰底色与轻描边；它们与单个悬浮按钮分开绘制，不依赖视频底色维持文字对比度。
- 所有控件取消 tooltip，包括按钮、空状态功能点、导出说明和进度条悬浮时间提示；保留底部时间读数、无障碍标签和说明。

悬浮玻璃的顶部高光按反馈柔化为 0.75px、中央白色 7.5%，沿圆角向两端淡出至透明；不再通过裁切完整描边制造顶部边框，避免胶囊两侧出现生硬的截断。

macOS 视频位于 MyGo 下面的独立 Metal 图层；UI 使用 alpha 叠加与视频合成，不为材质效果读取整帧视频。标题栏通过 `c.TitleBar()` 避开系统窗口控制键；这一安全区适配是原生窗口所需的布局差异。

顶部操作区位于系统窗口按钮占用的整条区域下方，不与 macOS 红绿灯同行。以 MyGo 返回的标题栏高度作为安全区，播放列表面板从安全区底部开始，按钮再向下留出 8 DIP；面板外边距 16 DIP，内部留白和按钮间距 8 DIP，折叠按钮与展开后的关闭按钮固定在同一位置；右侧操作按钮也使用 24 DIP 外边距。Windows 的窗口按钮宽度及 DPI 变化不会再扩大操作按钮的水平缩进。全屏时系统安全区为零，恢复普通内容边距。

## 复查方法

使用同一段合成灰色网格视频对照 web 和本机应用的按钮、播放列表、投影菜单、音量/速度弹层，再检查空状态和设置关闭按钮。浏览器测量和人工截图检查不代替完整的 UI 等价验收；不新增 UI 自动化或 e2e 测试。
